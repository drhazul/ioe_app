# Faltantes y Sobrantes

Ruta inicial: `/faltantes-sobrantes/reporte-faltantes`.

`Reporte de Faltantes` incluye boton `Reporte de ajustes`. Consulta resumen por sucursal/QNA equivalente a Access `FYS_REPORTE_CIERRE_QNA_RESUMEN` y presenta diario SAP con cuentas de sobrante, faltante y pago de faltantes.
